# 🚀 Messenger - Современный веб-мессенджер

Полнофункциональный мессенджер с красивым дизайном, поддержкой личных и групповых чатов, голосовых/видео звонков и многого другого.

## ✨ Возможности

### 🔐 Аутентификация
- Регистрация с подтверждением email
- 6-значный код подтверждения
- Безопасный вход с JWT токенами
- Хеширование паролей с bcrypt

### 💬 Чаты
- Личные чаты (1-на-1)
- Групповые чаты
- Поиск чатов и пользователей
- Счетчик непрочитанных сообщений
- Последнее сообщение в превью чата

### 📝 Сообщения
- Отправка сообщений в реальном времени
- Редактирование своих сообщений
- Удаление сообщений (у всех или только у себя)
- Копирование текста сообщений
- Индикатор "печатает..." в реальном времени
- Контекстное меню для сообщений (ПКМ)

### 📞 Звонки
- Голосовые звонки (WebRTC)
- Видео звонки
- Отключение микрофона
- Отключение камеры
- Входящие/исходящие звонки
- Мелодия вызова

### 🔔 Уведомления
- Звуковые уведомления о новых сообщениях
- Звук входящего звонка
- Счетчики непрочитанных сообщений

### 🎨 Дизайн
- Современный темный дизайн
- Плавные анимации и переходы
- Адаптивный дизайн
- Font Awesome иконки
- Градиенты и эффекты

### 📱 Статусы
- Индикатор "онлайн/офлайн"
- Отображение активных пользователей
- Автоматическое обновление статусов

## 🛠 Технологии

### Backend
- Node.js + Express
- Socket.io (WebSocket)
- PostgreSQL
- JWT аутентификация
- Nodemailer (отправка email через Brevo SMTP)
- bcrypt (хеширование паролей)

### Frontend
- Vanilla JavaScript (без фреймворков)
- Socket.io Client
- WebRTC для звонков
- Font Awesome иконки
- CSS анимации

## 📦 Установка

### 1. Установка зависимостей

```bash
npm install
```

Необходимые пакеты:
- express
- socket.io
- pg
- bcrypt
- jsonwebtoken
- nodemailer
- cors
- body-parser

### 2. Настройка переменных окружения

Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

Отредактируйте `.env` и укажите свои данные:

```env
# Database Configuration
DB_USER=messengeruser
DB_HOST=localhost
DB_NAME=messenger
DB_PASSWORD=your_secure_password
DB_PORT=5432

# JWT Secret (обязательно измените в продакшене!)
JWT_SECRET=your_random_secret_key_here

# SMTP Configuration (для отправки email)
SMTP_HOST=smtp-relay.brevo.com
SMTP_PORT=587
SMTP_USER=your_brevo_email
SMTP_PASS=your_brevo_api_key
```

### 3. Настройка PostgreSQL

Создайте базу данных и пользователя:

```sql
CREATE DATABASE messenger;
CREATE USER messengeruser WITH PASSWORD 'your_secure_password';
GRANT ALL PRIVILEGES ON DATABASE messenger TO messengeruser;
```

Таблицы создадутся автоматически при первом запуске сервера.

### 4. Настройка SMTP (для email-подтверждения)

Для работы регистрации нужен SMTP сервер. Рекомендуется Brevo (бывший Sendinblue):

1. Зарегистрируйтесь на https://www.brevo.com/
2. Перейдите в SMTP & API → SMTP
3. Скопируйте логин и создайте API ключ
4. Укажите данные в файле `.env`

Альтернативы: Gmail SMTP, Mailgun, SendGrid и др.

### 5. Добавление звуков

Поместите файлы `notification.wav` и `ringtone.wav` в папку `/public/`.

См. `public/AUDIO_INSTRUCTIONS.md` для подробностей.

### 6. Запуск сервера

```bash
node server.js
```

Или с автоперезагрузкой при разработке:

```bash
npm run dev
```

Сервер запустится на `http://localhost:3000`

## 🎯 Использование

1. Откройте `http://localhost:3000` в браузере
2. Зарегистрируйтесь (получите код на email)
3. Войдите в аккаунт
4. Создайте чат с другим пользователем
5. Начните общаться!

## 📱 Функционал

### Отправка сообщений
- Введите текст в поле ввода
- Нажмите Enter или кнопку отправки
- Shift+Enter для новой строки

### Редактирование/удаление сообщений
- ПКМ на сообщении
- Выберите действие из контекстного меню
- Редактировать/удалить можно только свои сообщения

### Создание чатов
- Нажмите иконку "✏️" в боковой панели
- Выберите "Личный чат" или "Групповой чат"
- Выберите пользователя(-ей)
- Для группы введите название

### Звонки
- Откройте личный чат
- Нажмите иконку "📞" для голосового звонка
- Нажмите иконку "📹" для видео звонка
- Собеседник получит уведомление

## 🔒 Безопасность

- Пароли хешируются с помощью bcrypt
- JWT токены для аутентификации
- Защита от SQL инъекций (параметризованные запросы)
- CORS настроен
- Email подтверждение при регистрации

## 🎨 Кастомизация

### Изменение цветовой схемы

В файле `public/styles.css` измените CSS переменные:

```css
:root {
    --primary-color: #667eea;
    --secondary-color: #764ba2;
    --bg-primary: #0f0f1e;
    --bg-secondary: #1a1a2e;
    /* ... */
}
```

### Изменение порта

В файле `server.js`:

```javascript
const PORT = 3000; // измените на нужный порт
```

## 🐛 Известные проблемы

1. **Звуки не работают**: Убедитесь, что файлы `notification.wav` и `ringtone.wav` находятся в папке `/public/`

2. **Email не отправляется**: Проверьте настройки SMTP в `server.js`

3. **Видео звонки не работают**:
   - Проверьте разрешения браузера на доступ к камере/микрофону
   - Используйте HTTPS или localhost
   - WebRTC требует современный браузер

4. **База данных не подключается**: Проверьте настройки PostgreSQL в `server.js`
